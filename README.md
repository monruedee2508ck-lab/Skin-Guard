# Skin Guard

ระบบประเมินความเสี่ยงและดูแลแผลกดทับ (Braden Scale, นาฬิกาพลิกตัว, NPIAP/PUSH, แนะนำวัสดุปิดแผล, ติดตามแนวโน้มการหาย)

เปิดใช้งาน: https://monruedee2508ck-lab.github.io/Skin-Guard/

- ข้อมูลผู้ป่วยและภาพถ่ายเก็บในเครื่องของผู้ใช้แต่ละคนเท่านั้น ไม่ถูกส่งขึ้นเว็บ
- เครื่องมือช่วยประเมิน ไม่ใช้แทนการตัดสินใจทางคลินิกของพยาบาลหรือแพทย์
