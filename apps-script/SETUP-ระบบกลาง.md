# ตั้งค่าระบบกลาง Skin Guard (Google Sheets + Google Drive)

ทำครั้งเดียว โดยหัวหน้าหอหรือผู้ดูแล ใช้คอมพิวเตอร์จะสะดวกที่สุด (iPad ใช้ Safari แบบ "ขอเว็บไซต์เดสก์ท็อป" ได้)

## 1. สร้าง Google Sheet
1. เข้า sheets.google.com ด้วยบัญชี Google ของหน่วยงาน
2. สร้างสเปรดชีตเปล่า ตั้งชื่อ เช่น `Skin Guard – ข้อมูลกลาง`

## 2. ใส่โค้ด Apps Script
1. ในสเปรดชีต เมนู **ส่วนขยาย (Extensions) → Apps Script**
2. ลบโค้ดเดิมในไฟล์ `Code.gs` ทั้งหมด แล้ววางโค้ดจากไฟล์ `Code.gs` ที่ได้รับ
3. แก้บรรทัด `const KEY = 'CHANGE-ME-TO-A-LONG-SECRET';` เป็นรหัสลับของหน่วยงาน ยาวอย่างน้อย 16 ตัว เช่น `SICU-2569-pRessure-9xQ7` (ถ้าได้ไฟล์ "Code-SkinGuard-พร้อมใช้.gs" มีรหัสใส่ไว้ให้แล้ว ข้ามข้อนี้ได้)
4. กดไอคอนบันทึก (💾)
5. เลือกฟังก์ชัน **setup** ในแถบด้านบน แล้วกด **▶ Run** → อนุญาตสิทธิ์ (Review permissions → เลือกบัญชี → Advanced → Go to … (unsafe) → Allow) ระบบจะสร้างแท็บ patients, history, turns, photos, log, admins และโฟลเดอร์ภาพ `SkinGuard-Photos` ให้

## 3. Deploy เป็น Web app
1. ปุ่ม **Deploy → New deployment**
2. รูปเฟือง ⚙ เลือกประเภท **Web app**
3. Execute as: **Me** · Who has access: **Anyone**
4. กด **Deploy** → กด **Authorize access** แล้วเลือกบัญชี (ถ้าขึ้นเตือน "Google hasn't verified this app" ให้กด Advanced → Go to … (unsafe) → Allow เพราะเป็นโค้ดของเราเอง)
5. คัดลอก **Web app URL** (ขึ้นต้นด้วย `https://script.google.com/macros/s/` และลงท้ายด้วย `/exec`)

## 4. เชื่อมต่อในแอป Skin Guard
1. เปิดแอป → เข้าสู่ระบบด้วยเลข OT → กดชื่อผู้ใช้มุมขวาบน → **เข้าโหมดผู้ดูแล (Admin)** → แท็บ **หอผู้ป่วย**
2. การ์ด **ระบบกลาง (Google Sheets)** ใส่ Web app URL และรหัสลับ (KEY) → **บันทึกและเชื่อมต่อ**
3. ขึ้นว่า "เชื่อมต่อสำเร็จ" ข้อมูลที่มีในเครื่องจะถูกส่งขึ้นระบบกลาง

## 5. บัญชีผู้ดูแล (Admin)
- หลังเชื่อมระบบกลางแล้ว กดชื่อผู้ใช้มุมขวาบน → **เข้าโหมดผู้ดูแล (Admin)** → แท็บ **ลงทะเบียน** ใส่ชื่อ-สกุล อีเมล และรหัสผ่าน
- **บัญชีแรก** ในระบบกลางได้รับอนุมัติทันที บัญชีถัดไปจะ "รออนุมัติ" จนผู้ดูแลกด **อนุมัติ** ในการ์ด "บัญชีผู้ดูแล (Admin)" แท็บหอผู้ป่วย
- รายชื่ออยู่ในแท็บ `admins` ของ Google Sheet (เก็บรหัสผ่านแบบเข้ารหัส ไม่เห็นรหัสจริง)
- ถ้าเคย Deploy โค้ดเวอร์ชันก่อนไว้แล้ว ต้องวางโค้ด Code.gs ใหม่ แล้ว Deploy → Manage deployments → ✏️ Edit → Version: New version → Deploy

## 6. เชื่อมต่อเครื่องอื่น
- ในเครื่องที่เชื่อมแล้ว กด **คัดลอกลิงก์ตั้งค่าให้เครื่องอื่น** แล้วส่งลิงก์ให้เครื่องอื่นเปิด **ครั้งเดียว** (ลิงก์มีรหัสลับ ส่งเฉพาะในกลุ่มหน่วยงาน)
- หรือใส่ URL และ KEY เองในการ์ดเดิม

## ภาพถ่ายรายเวรและการลบภาพอัตโนมัติ (อัปเดต ต.ค. 2569)
- แท็บ **ภาพรายเวร** แสดงทุกภาพที่ถ่าย 1 แถวต่อ 1 ภาพ: วันที่ · เวลา · เวร (เช้า 08–16 / บ่าย 16–24 / ดึก 00–08) · HN · ประเภทภาพ (ผิวหนังแรกรับ / ผิวหนังประจำวัน / ภาพแผล) · ตำแหน่ง · สภาพผิวหรือขนาดแผล · ผู้บันทึก (OT) · ภาพย่อในเซลล์ · ลิงก์ภาพเต็มใน Google Drive · วันที่จะลบอัตโนมัติ (ภาพล่าสุดอยู่บนสุด)
- **ลบภาพอัตโนมัติ** เมื่อครบ 7 วันนับจากวันที่ถ่าย หรือเมื่อจำหน่ายผู้ป่วย ทั้งในเครื่อง iPad และในระบบกลาง (ไฟล์ใน Drive ถูกย้ายไปถังขยะ และ Google ลบถาวรภายใน 30 วัน ถ้าต้องการลบทันทีให้ล้างถังขยะของ Drive)
- ระบบกลางลบให้ทุกวันเวลา 01:00 น. และทุกครั้งที่มีเครื่องส่งข้อมูลเข้ามา (ไม่เกินชั่วโมงละครั้ง) บันทึกจำนวนภาพที่ลบไว้ในแท็บ log
- ตัวเลขคะแนน ขนาดแผล และประวัติการประเมินยังอยู่ครบ ลบเฉพาะไฟล์ภาพ
- **ถ้าเคยติดตั้งโค้ดเวอร์ชันก่อน:** วางโค้ด Code.gs ใหม่ทับ → บันทึก → เลือกฟังก์ชัน **setup** → ▶ Run (อนุญาตสิทธิ์เพิ่ม "ตั้งเวลาทำงาน") → Deploy → Manage deployments → ✏️ Edit → Version: **New version** → Deploy (URL เดิมใช้ต่อได้)

## ตัวชี้วัดคุณภาพและ Braden รายวัน (อัปเดต ต.ค. 2569)
- แท็บ **Clinical Outcomes**, **Nursing Performance** และ **QA & Research**: ตัวชี้วัดรายเดือนแบบเดียวกับหน้า Nursing Quality & Patient Safety Analytics (ค่า สถานะ เป้าหมาย) อัปเดตอัตโนมัติทุกครั้งที่ผู้ดูแลเปิดหน้า Analytics และทุก 3 ชั่วโมงเมื่อเปิดแอป เดือนเดียวกันจะเขียนทับด้วยค่าล่าสุด
- Nursing Performance มีรายกิจกรรม 8 ข้อ: พลิกตะแคงตัว · ประเมินผิวหนัง · ยกส้นเท้า · หัวเตียงน้อยกว่า 30° · ตรวจผิวทุกครั้งที่พลิก · จัดท่าตะแคง 30° · ตรวจแผ่นป้องกัน · ประเมิน Braden
- แท็บ **Braden รายวัน**: วันที่ เวลา HN ชื่อ-สกุล คะแนน Braden รวมและรายด้าน ระดับความเสี่ยง จำนวนแผล PUSH สูงสุด และผู้ประเมิน (1 แถวต่อผู้ป่วยต่อวัน ใช้ค่าล่าสุดของวัน)
- แท็บ **แผลกดทับ** (เมื่อเกิดแผลแล้ว): วันที่ HN ชื่อ แผลที่ ตำแหน่งแผล ชนิด ระดับแผล ขนาด ยาว × กว้าง × ลึก พื้นที่ คะแนน PUSH วัสดุที่ใช้ปิดแผล และเวลาเปลี่ยนวัสดุล่าสุด (1 แถวต่อแผลต่อวัน)
- ภาพถ่ายผิวหนังและภาพการประเมินแผลอยู่ในแท็บ **ภาพรายเวร** (ลบอัตโนมัติเมื่อจำหน่ายหรือครบ 7 วัน)
- หลังวางโค้ดใหม่ ให้ Run **setup** 1 ครั้ง แล้ว Deploy → Manage deployments → Edit → New version

## ข้อมูลที่เก็บ
- Sheet `patients` ข้อมูลผู้ป่วยรายคน (Braden, ปัจจัยเสี่ยง, แผล) · `history` ประวัติที่ลงชื่อบันทึก · `turns` เวลาพลิกตัวล่าสุด · `photos` รายการภาพ (ข้อมูลระบบ) · `ภาพรายเวร` ภาพพร้อมวันที่ เวลา และเวร · `log` ใคร (เลข OT) บันทึกอะไร เมื่อไร
- ภาพถ่ายเก็บในโฟลเดอร์ Google Drive ชื่อ `SkinGuard-Photos` ของบัญชีที่ Deploy (ไม่เปิดสาธารณะ)

## ข้อควรระวัง
- เป็นข้อมูลสุขภาพตาม PDPA ควรได้รับอนุญาตจากฝ่ายการพยาบาล/IT/DPO ของโรงพยาบาลก่อนใช้กับผู้ป่วยจริง
- ใครมี URL + KEY จะอ่าน/เขียนข้อมูลได้ เก็บรหัสลับไว้เฉพาะในหน่วยงาน ถ้ารั่วให้เปลี่ยน KEY แล้ว Deploy ใหม่ (Manage deployments → Edit → New version)
- เมื่อแก้โค้ด Apps Script ต้อง Deploy เวอร์ชันใหม่ทุกครั้ง
